# USB DP/DM — R6 设计方案（已推导，未布铜）

状态：**未布线**（原生 DRC 未连接中 USB 仍为 8 项）。本页是可直接执行的方案与阻断清单，不是完成声明。

## 0. 前提与判断
- ESP32-S3 USB 为 **USB 1.1 Full-Speed 12 Mbps**。U1→J1 约 40 mm 走线相对 FS 边沿时间属电短线，90 Ω 偏差影响很小；仍执行成对耦合、连续参考面、长度匹配、每网过孔 ≤2（DRU）。
- 叠层 C1 估算：F.Cu 微带 / In1 GND，W/S = 0.22/0.15 mm → 89.9 Ω（2D 求解，**非板厂确认**）。
- 注意：KiCad 仅把 `_P/_N` 或 `+/-` 结尾的网识别为差分对，`/USB_DP`、`/USB_DM` 不会触发 DRU 中 diff_pair_gap / skew / uncoupled 约束（via_count、track_width 仍生效）。长度匹配需自行计算并记录。可选后续：改名为 `USB_D_P/USB_D_N`（原理图改动，parity 复核）。

## 1. 通道（S5 后原生可行性）
- 胖线检查（2W+S = 0.59 mm + 网类间距）：**F.Cu 上 U2 北侧 ↔ U1.13/14 西侧已连通**（S5 平面清理后才出现；S5 前仅 B.Cu 连通）。参考面 In1 GND 实心。

## 2. 手性（拓扑）问题与解法
- 平面内一对线的左右手性不变。U1.13=DM(y 82.78) 在北、U1.14=DP(84.05) 在南，从西侧出线 ⇒ 向东到达时 DM 在左。
- 现原理图 U2：#1/#6 = DP（西 x=123.55），#3/#4 = DM（东 x=125.45），⇒ 自 U2 向北出发 DM 在右 ⇒ **U2→U1 必须交叉一次**；J1（B7 DM 124.25 / A6 DP 124.75 / A7 DM 125.25 / B6 DP 125.75）到 U2 还需 1–2 次交叉。每次交叉一网 +2 过孔 ⇒ 必然超过 DRU `via_count ≤ 2`。
- **解法：对调 USBLC6-2SC6 通道**（两通道对称，电气等价）：原理图 U2 #1/#6 → USB_DM，#3/#4 → USB_DP（交换标号 uuid `abbf3dad`/`70b69446`、`c1f19bd1`/`93decf47` 的文字；PCB U2 焊盘网同步；`netlist.csv` 第 233–239 行；`ELECTRICAL_REVIEW.md` U2 行）。之后：U2→U1 无交叉；J1 仅内侧 A6/A7 一次交叉，**只 DP 用 2 个过孔**，DM 0 个。

## 4. 仍阻断（须先做，属充电输入区局部重布，需电源路径评审）
1. **U2.5 VBUS**：现 F.Cu 自 U2.5 向北出线并西北斜穿 DM 路径 → 改为就地过孔 (≈124.5,116.2) + B.Cu 去 VBUS；但 B.Cu 被 R3 遗留阶梯线挡住：/CHG_ISET (y=116.75, x 115–127)、/CAM_3V3 (y=117.5)、/VBAT、/CAM_PWR_EN。需先拆除重布这些线（同时也是 PI 改善）。
2. U2 北侧 DM/DP 需 1.9 mm → 0.37 mm 收拢，收拢段 ≤3 mm。
3. J1 南侧（壳体下）过孔区域的障碍、阻焊盖油与连接器厂家禁布需核对 HRO TYPE-C-31-M-12 图纸。
4. 换层（无）/参考面：全程 F.Cu over In1；A6 B.Cu 跳线 1 mm 以 In2(3V3) 为参考，旁加 GND 缝合过孔。
