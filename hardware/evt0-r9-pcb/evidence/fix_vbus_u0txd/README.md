- 断点：主岛 `915f1af2` 止于 (1140.4,645)，TP1 岛 `5f18f28b` 起于
  (1235,645)，L1 y=645 同轴缺口 94.6mil，桥接带无任何走线/过孔。

## U0TXD：U1.37↔J6.3 主干（4 过孔 + 6 走线）

- 路径：U1_37 (1899.49,1700.195) → L1 短接 → 过孔 (1894,1700.2) →

  J6_4/5/6 焊环）已全数拆除重布。

## 阻断判定（本轮新证实，维持不强行布线）

- **U0TXD R30_2/R33_1 分接**：VBAT_ADC L2 x1839.5（y480–1800.2 整板高墙）
  + VSYS L 型（x1493.6/对角/x1606.7）+ 3V3 过孔 (1642,1040) +
  CAM_Y2/Y5 L1 纵线 + STRAP46/GND 结构六重封锁；连通需 ≥3 次换层且
  穿越 CAM 数据线区，本轮不强行。
- **CHG_CE_N U3_4**：VBUS 对角 (616,200.2)→(814.3,398.5) + VBUS y200.2
  横线 + VBAT_ADC 墙 + VBAT_CONN (658.7,263) 拐角互锁，过孔无合法位；
  一次尝试产生 7 项违规已拆除（drc_r9_23/24）。
- **VBUS J1 焊盘 A4B9/B4A9（e23e38/e23e37）**：TH 焊盘多边形
  0.6×1.3mm，钻孔 Ø1.417mm 覆盖全部有效焊环，走线穿过孔洞无铜可接。
  **封装缺陷**：需按 J1（USB-C 24P）数据手册修订焊盘焊环，
  属封装库变更，列入下一轮，不以铜皮技巧绕行。
- **CAM_PWR_EN U1_15**：STRAP46（x1251.2 纵线+y1190.5 横线+对角）+
  DISP_PWR_EN y1064.1/1106.9 + CAM_2V8 过孔 (1106.5,1090) 合围成笼。
- **CHG_ILIM/CHG_TD/CHG_ISET（U3 顶排/右列）**：VBUS y581.4 横线 +
  VBUS 对角 + BAT_NTC 过孔 (640.9,509.5) + EPAD + VBAT/VSYS 纵线互锁。
- **CAM_DVDD（0 铜）**：R16_2/C16_1/J3_10 三焊盘全无走线，C16_1 位于
  U3 围栏区内；需独立电源走线轮次（可能涉铺铜决策），本轮未动。
- **CAM_Y6、MIC_SCK/WS/SD**：跨板长线，自动布线器无路径，CAM/MIC 信号
  区密布，留待专项。
