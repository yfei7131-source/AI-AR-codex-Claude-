# USB_DP / USB_DM 差分整改 — 阻断项（未布线）
## 现状（zy_pcb，非原生）
- USB_DP：J1.A6(124.75,122.05) J1.B6(125.75,122.05) U2.1(123.55,119.64) U2.6(123.55,117.36) U1.14(116.25,84.05)；USB_DM：J1.A7(125.25,122.05) J1.B7(124.25,122.05) U2.3(125.45,119.64) U2.4(125.45,117.36) U1.13(116.25,82.78)。两网现有铜均为0。
- J1 端 A/B 焊盘顺序交叉（DP/DM 间距 0.5mm 内），J1→U2 区域被 GND桥/VBUS/CC/3V3 占用；U2→U1 约 35mm 直线距离。
- 工程规则：USB类 线宽0.2、差分间距0.15、diff_pair_via_gap 0.25、via 钻孔0.25（**低于板级通孔最小0.30mm，需改**）；DRU 写明"叠层与阻抗仍阻断，用板厂计算器核对"。
## 阻断参数（缺失，须由用户/板厂给出）
1. 层叠：PCB 无 (stackup) 定义，仅板厚 1.0mm；缺各层铜厚、介质厚度/Dk、阻焊、表面处理。
2. 目标：USB2.0 90Ω差分、公差、是否按 F.Cu 微带+In1 GND 参考计算线宽/间距。
3. 板厂工艺能力：最小线宽/线距/过孔、是否允许0.25孔。
4. 长度匹配目标与 U2(ESD/保护) 位置约束、J1 A/B 引脚合并拓扑(stub 限制)。
5. 回流：F.Cu 差分段下方 In1(GND) 是否连续；需 KiCad 重铺后确认无割裂。
## 在上述参数到位前不得
用现有单线布线器分别布 DP/DM（无耦合/等长/阻抗控制）；以1.0mm长度差规则代替阻抗分析；放宽规则或改用0.25孔通过。
## 后续步骤
补叠层→阻抗计算→先在J1–U2局部重排 CC/GND/VBUS 腾出耦合通道→耦合布线(DP/DM同层、间距0.15、对称过孔)→原生DRC(含 diff pair/skew)+回流检查。
