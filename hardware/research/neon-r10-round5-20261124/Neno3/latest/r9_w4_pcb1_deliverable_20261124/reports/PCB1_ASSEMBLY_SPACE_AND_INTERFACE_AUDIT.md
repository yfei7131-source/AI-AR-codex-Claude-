# PCB1（118 器件）装配空间、可导入封装与接口核查报告

## 1. PCB1 精确 8 点异形板框与分区占用分析

从 `R9-Gemini-W4-PCB1.zip` 内 `PCB1-copper.json` 提取的精确板框（6 层，铜距板边 `10 mil = 0.254 mm`，最小间距 `5.98 mil = 0.152 mm`）：
- **前端段（`Y = 0.00 ~ 4.20 mm`，宽 `5.80 mm`）**：紧邻底层 `ANT1`（`L2 [0.63, 4.47 -> 4.38, 6.42] mm`）射频天线，**严禁放置 J2/J3 金属连接器**。
- **中前宽段（`Y = 4.20 ~ 14.00 mm`，宽 `8.20 mm`）**：已被 `U1` 主控（`L1 [-0.09, 5.36 -> 7.84, 12.84] mm`）、`U12 (TPD2E001DRYR)`、`U2/U4/U9/U14/Q1` 占满，无可用空窗。
- **中段（`Y = 14.00 ~ 35.32 mm`，宽 `5.80 mm`）**：已被 `J1 (J_BTB_L)`、`U15/U16/U20`（摄像头电平转换）、`U6/U11/U13`（摄像头 LDO）、`U10`（功放）、`U22 (TPS2553DRVR)` 与阻容矩阵密集占满，无可用空窗。
- **尾段顶层（`Y = 36.20 ~ 45.75 mm`，宽 `5.80 mm`，L1）**：**全板唯一零器件、零顶层走线的可用装配窗**（底层 L2 被 `MK1` `[0.55, 41.20 -> 4.46, 45.46] mm` 及 `U19/R15/R17` 占用，因此尾段禁止使用直插通孔件，必须纯 SMD）。

## 3. PCB1 接口与保护电路现状核查

- **USB / 充电保护链（已证实存在）**：
  - `U12`（`TPD2E001DRYR`，`L2 (0.92, 10.14) mm`）：`Pin 1 = USB_DP`、`Pin 2 = GND`、`Pin 3 = USB_DM`、`Pin 4 = NC`、`Pin 5 = VBUS_5V_USB`、`Pin 6 = NC`；**布局优化建议**：当前距尾段 `J3` 约 `31 mm`，在 R10 试验工程中建议迁至 `J3` 紧邻处（`≤ 3 mm`）以缩短 ESD 泄放路径。
  - `U22`（`TPS2553DRVR`，`L1 (1.59, 23.51) mm`）+ `R38`（`RC0201FR-0761K9L`）：构成 `VBUS_5V_USB → VBUS_5V` 精密限流保护开关。
- **板外飞线测试点（已证实存在）**：`TP2 (VBAT_L)`、`TP6 (SPK_L_N)`、`TP7 (SPK_L_P)` 已在 PCB1 上落位，可用于合规承接 `BAT1`/`SPK1` 外接线以关闭 2 项 `MISSFOOTPRINT` ERC 错误。
- **J2 多渠道采购闭环**：插座 `BM28B0.6-24DS/2-0.35V(53)`（[JLCPCB `C5577343`](https://jlcpcb.com/partdetail/6495731-BM28B0_6_24DS_2_0_35V_53/C5577343) 现货 `153`、[DigiKey `H125603CT-ND`](https://www.digikey.com/en/products/detail/hirose-electric-co-ltd/BM28B0-6-24DS-2-0-35V-53/7793566) 现货 `4,544`）；配对插头 `BM28B0.6-24DP/2-0.35V(53)`（[DigiKey `H125591CT-ND`](https://www.digikey.com/en/products/detail/hirose-electric-co-ltd/BM28B0-6-24DP-2-0-35V-53/7793554) 现货 `2,862`）。
