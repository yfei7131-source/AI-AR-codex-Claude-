# 智元跃动 AI/AR 智能眼镜 V1.0（EVT-1 H03-R8）基于 PR #58（130 项基线）的 PCB3 联合布局、多网络逃线与设计增量方案

**验证声明（重要）**：本交付基于 [GitHub PR #58（commit `1b69c06`）](https://github.com/yfei7131-source/AI-AR-codex-Claude-/pull/58) 与 [PR #59 / `neon-round3-20261124/neon-3`](https://github.com/yfei7131-source/AI-AR-codex-Claude-/tree/hardware/research/neon-round3-20261124/hardware/research/neon-round3-20261124/neon-3) 的真实坐标与约束数据，**已停止使用旧 R3 云端工程（134 项基线）**。因当前无与 PR #58（130 项基线）一致的合格云端副本，**本方案为离线几何求解与可执行设计增量（Design Delta），不冒充原生 EasyEDA Pro ERC/DRC 验证，不上传 GitHub，维持 `NOT FOR FAB` 状态**。

## 1. 唯一基线与核心几何瓶颈诊断

- **唯一基线**：[PR #58 `STATE.md`](https://github.com/yfei7131-source/AI-AR-codex-Claude-/blob/hardware/evt1-h03-r8-codex-20261124/hardware/evt1-native-eda-20261118/h03-codex-r8-20261124/STATE.md) 确认三板严格原生未连通为 `339 / 232 / 130 = 701`（0 间距/短路，6 ERC fatal），**PCB3 唯一基线为 `130` 项连接错误**（较 R7 132 项通过底层 `U1.3↔U1.2` 与 `C8.2↔C11.2` 局部 GND 走线净减 2 项；现有 41 颗 GND 盲孔：`22 BV_L1_L2 + 19 BV_L5_L6`）。
- **锁定红线**：PCB3 板宽 **`5.20 mm`（`204.72 mil`）**、40 g 整机目标、双目透明 AR 架构；走线 `≥ 4 mil`、铜距 `≥ 6 mil`、孔壁距 `≥ 11.8 mil`、过孔盘到板边 `≥ 13.78 mil`（0.35 mm）、走线到板边 `≥ 11.85 mil`、`BLE_RF`/`DECR` 隔离 `≥ 12 mil`。
- **`U11` / `U10` 双面重叠区根因（PR #58 原生坐标系实测）**：
  - 顶层 `U11`（`nRF5340-CMAA`，4.390 × 3.994 mm = `172.83 × 157.24 mil`）投影覆盖 `X ∈ [15.94, 188.78] mil, Y ∈ [283.59, 440.83] mil`（`U11.A3 = (33.46, 313.98)`，`U11.L9 = (171.26, 396.66)`）。
  - 底层 `U10`（Class-D 功放 WLCSP9，`~51 × 51 mil`）现位于中心 `(166.55, 383.05) mil`，覆盖 `X ∈ [141.05, 192.05] mil, Y ∈ [357.55, 408.55] mil`，与 `U11` 顶层投影产生 **`2,434.23 mil²`（93.6% 本体面积）双面重叠**，直接压死 `U11` 右侧 `J/K/L` 列（含 `L9/K4/K5/J4/J5`）下方的底层换层走廊与回流过孔空间。
  - 同时，扬声器焊盘 `SPK_R_N` `(32.1, 575.4)` / `SPK_R_P` `(75.4, 575.4)` 与下拉电阻 `R3.1` `(125.8, 621.9)` / `R4.1` `(177.0, 598.2)` 均位于 `Y ∈ [575, 622] mil` 音频区，导致 `U10` 与其负载被迫远距跨区绕线。

## 4. `K5 → L9` ECO 与固件兼容性评估

- **原厂电气与寄存器核证**：经核对 [Nordic nRF5340 Pin assignments](https://docs.nordicsemi.com/r/bundle/ps_nrf5340/page/chapters/pin.html)（Table 3 WLCSP95）与 [Nordic I2S 规范](https://docs.nordicsemi.com/r/bundle/ps_nrf5340/page/i2s.html)，`L9 (P0.15)` 复用为 `QSPI IO2 / General purpose I/O`（PCB3 无外部 QSPI），可合法通过 `PSEL.SCK (0x564)` 映射为 I2S 位时钟；无低频或射频限制。
- **ECO 操作防回归要点**：在基于 PR #58 `.epro2` 实施 `U11.K5 → NC`、`U11.L9 → I2S_BCLK_1V8` 时，**必须同步清理原 `K5` 顶层残留悬空线段（如旧工程中的 `e414`/`e415` 类孤岛）**，防止引入 `+1` 虚假连接错误。
- **固件映射一致性**：核实仓库 `firmware/` 当前仅含 ESP-IDF 源码，无 Zephyr `.dts`/`.overlay`；交付包内附可直接合入 nRF5340 Application Core 的 `nrf5340_pcb3_r8_i2s_eco.overlay`（禁用 `&qspi`，映射 `I2S_SCK_M → P0.15`，并在 `i2s0_sleep` 启用 `low-power-enable` + `bias-pull-down` 配合硬件 `R3.1`/`R4.1`）。
