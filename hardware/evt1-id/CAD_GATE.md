# 真实三维装配模型的输入与验收门槛

母版是用户已确认的 ZY 银色渲染图，原件见 `references/ZY_AIAR_Glasses_ID_MASTER.png`。本轮冻结其视觉特征，不从像素推算毫米尺寸。图内爆炸结构、钛材、40 g、光机和空间音频均不能作为实际零件或测量证据。

`ASSEMBLY_INPUTS.json` 列出15个部件/模块的受控几何输入槽位。STEP、料号、包络、安装姿态、公差和实测质量目前均缺失；没有生成可声明装得下的三维装配，也没有碰撞/光路/工艺通过结论。旧 `hardware/mechanical/` 是 Halo 台架，不是此母版整镜CAD。

| Gate | 必须形成的具体产物 | 当前状态 |
|---|---|---|
| C01 外观与尺寸基准 | 正/侧/上受控尺寸图，镜框/镜腿/鼻托/铰链基准与允许外形截面；左右按佩戴者视角 | 母版确认；尺寸/公差缺失 |
| C02 双目真实光学 | 左右光机、驱动与配对波导的料号/版本/STEP，耦入出与眼位基准，处方插片/鼻托净空 | BLOCKED；不能用一颗微显示尺寸代替 |
| C03 储能与电源 | 两个完整受保护包的尺寸、质量、NTC/保护线束和安全包络；实际电源路径元件/板形 | BLOCKED；不把两电芯直接并联 |
| C04 左右分板与互连 | 左主控/右音频/前框小板三维板形、层叠、器件高度、连接器与线束，静态/动态FPC分区 | 架构与接口清单已有；几何和针序待冻结 |
| C05 热、RF与声学空间 | 金属框天线窗口/净空、热源至皮肤/电芯路径、扬声器声腔与麦孔的真实包络 | BLOCKED；没有RF或温升实测 |
| C06 装配及公差 | 带版本BOM的整机STEP、镜腿截面与纵向堆叠图、装配顺序及公差/干涉报告 | NOT RUN；不能用示意块的无碰撞推导真实适配 |
| C07 质量与配重 | 各实购物料称重、左右/前后重心、鼻梁/耳后载荷及配镜版独立记录 | 仅50 g目标分配；实测质量未知 |
| C08 物理验收 | 灯/采集/故障同时观测、电池保护与NTC故障、电/光/热/无线/结构疲劳及佩戴记录 | NOT RUN；没有制造/实机放行 |

先以完整左右光学与电芯实物输入判断截面，再设计板形和FPC。器件不能适配时先优化光学、结构与集成度；若仍冲突，提出带具体尺寸/重量证据的变更，不能静默加粗镜腿、改单目或取消左右储能。

40 g挑战、50 g首轮设计、55 g警戒继续适用。`MASS_BUDGET.json` 为用户目标分配，不是物料实际重量；公开候选波导约16 g与14 g光学分配的冲突见 `OPTICS_SELECTION.md`，完整口径未确认前不得据此冻结BOM或虚构整机重量。
