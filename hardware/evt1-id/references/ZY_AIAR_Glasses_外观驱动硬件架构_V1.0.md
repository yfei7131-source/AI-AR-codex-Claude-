# ZY AI/AR Glasses｜外观驱动硬件架构 V1.0

**版本**：ID-HW-A01（概念架构，可执行设计输入，非生产 BOM）  
**日期**：2026-11-12  
**工业设计输入**：用户提供的《ZY AI/AR Glasses》三视图/爆炸效果图。  
**软件及工程基线**：`yfei7131-source/AI-AR-codex-Claude-`，`hardware/evt0-r3-h01-h03-20261112`，commit `164067e6cc5e7fb021a6232a775b153f0bcfd1fe`。现有 R3 为 EVT-0 电子验证板，不是可佩戴主板。  
**冻结边界**：原有 F01–F22（16 P0、5 P1、1 预研）不删减；AR 必须为眼前真实透视光学显示；全部电池安全、隐私联锁、射频、光学及佩戴结论须以真实样件验收。

## 1. 产品目标与工业设计约束

设计以效果图**可见的外观语言为目标**：银色轻量金属全框、微矩形圆角镜片、鼻梁中央摄像头、极小外向可见隐私指示灯、两片透明 AR 波导镜片、精密纤薄铰链、左右连续纤细镜腿、镜腿侧面触控/状态灯、开放式耳旁扬声器、右镜腿尾部 USB-C、左右分布式电池。左右镜片在效果图中都有 HUD，因此**双目显示是整机工业设计方向**；不允许在工程推进中默默变成普通显示屏或单目，若实物约束无法满足需提交设计变更评审。

效果图是**概念渲染**而非真实 CAD/厂商图纸，不能据此推断尺寸、镜片兼容性、40 g 质量、双目 FOV、真实彩色投影、续航或防水性能；必须在 EVT-1 前建立可量测 3D 包络模型。

## 2. 物理模块分布（设计假设，须由三维堆叠验证）

| 区域 | 功能与推荐物理位置 | 必须解决的问题 |
|---|---|---|
| 鼻梁/前框中心 | 中置 AI 相机；外向隐私指示灯与硬件供电联锁；极短相机 FPC | 中梁强度、相机模组视场、隐私灯故障检测、处方镜片与鼻托净空 |
| 左右镜框上缘/铰链根部 | 左/右各一组微显示光机及波导耦入光路；独立校准基准 | 两光机尺寸、瞳距范围、眼盒、入耦角、公差、遮挡、双目校准 |
| 左镜腿前段 | 低功耗主控/射频通信 PCB、相机与光机互连、电源管理分支、触控 | 佩戴侧热、天线与金属框相互影响、主控 PCB 截面尺寸 |
| 左镜腿后段 | 左侧电芯包、天线避让空间、麦克风之一 | 电芯保护/NTC、耳后弯折、天线与电芯隔离 |
| 右镜腿前段 | 蓝牙通话音频 SoC/Codec、右光机驱动或接口、IMU、触控 | HFP/A2DP 与 BLE 共存、PCB 密度、音频同步 |
| 右镜腿耳侧 | 右侧开放式定向扬声器、麦克风之二、另一电池包 | 防漏音/啸叫、密封声腔、温升及声学路径 |
| 右镜腿尾端 | USB-C 充电调试口、ESD/保护、应力释放结构 | 防汗液、铰链防水路径、供电/充电温升、连接器加固 |
| 镜片/鼻托 | 两片透视波导及可选配方镜片插片，独立可调鼻托 | 不得阻挡波导眼盒；验光轴位、镜眼距、整体重量另测 |

**布线原则**：前框→铰链→左右镜腿采用 FPC/刚挠结合或可拆 FPC；铰链处必须有动态弯折半径和寿命要求。摄像 DVP/高速显示链路经过铰链时需独立 SI/EMI 与共模评估。任何光机连接器均以供应商图纸为准，禁止沿用 R3 J4 虚拟 QSPI 引脚当最终接口。

## 3. 系统框图（功能分层而非已验证连线）

```text
                 [鼻梁 AI 摄像头] ─── [物理隐私联锁/状态指示]
                          │ 受控供电 + 数据
          ┌───────────────┴────────────────┐
          │        左镜腿主控 + 无线        │
          │   事件/相机/低功耗任务调度      │
          └───────┬────────────┬──────────┘
           BLE / Wi-Fi       双目显示指令/图像
                  │            │
            [iPhone App]    [左/右显示控制与微光机]
                  │            │
           同意后的 AI       [左/右透视波导]
                  │
               OCR/导航/语音/HUD内容

  [右镜腿独立蓝牙音频 SoC] ⇄ HFP/A2DP ⇄ [iPhone 通话音频]
          │                      
     [麦克风阵列/开放式扬声器]

 [USB-C] → [合规充电/保护/电源路径] ← [左/右独立受保护电芯]
                              │
                   [分路稳压、电量/NTC、故障切断]
```

### 3.1 主控选择
- **验证平台不废弃**：现有 ESP32-S3 N16R8 + ESP-IDF 固件继续服务 EVT-0 的摄像、BLE、媒体协议与电源联锁。
- **可穿戴版不强制照搬**：同时研究「S3 + 独立 HFP 音频 SoC + 显示桥接」与「更高集成度可穿戴 SoC/音频平台」两条方案，按开发权限、实际功耗、系统体积、射频认证和固件移植成本进行 A/B Gate。不能因 S3 有 BLE 就声称支持经典蓝牙通话；S3 不支持 Bluetooth Classic。
- 高算力 AI/OCR/导航主推手机与云端；眼镜只做低延迟采集、交互、显示、安全控制，降低镜腿发热。

### 3.2 真 AR 光学
- **产品目标**：左右眼各一套完整的显示驱动—微光机—耦入/耦出波导光学通道，透明显示及处方镜片可同时使用，整机佩戴时可独立校准双目。
- **研发选型**：可向 JBD 等厂商询问 0.13 英寸 MicroLED 微显示、驱动与配套双目波导供应链；公开器件的 640×480、60 mW 为**单微显示器件特定工况公开参数**，不是完整光机、双目光学、系统耗电或整机重量。全彩能力必须由具体模块确认，不能把单色 Hummingbird 型号标成全彩。
- **台架独立验证**：沿用 Brilliant Halo/官方 SDK 验证 HUD 格式和显示交互；Halo 的光机与屏幕规格不等于本产品两眼可直接集成。
- 冻结前必要资料：左右光机 STEP、波导 STEP、FOV、出瞳/眼盒/眼距、支持瞳距与处方插片公差、颜色/亮度、光机电流、显示协议、驱动 SDK、供电时序及采购条件。

### 3.3 电池与充电
- 必须保留左右**分布式**储能的工业设计目标。初期采用两个独立保护、温度采样、分路限流并有隔离的电池模块评估；统一电源路径和左右充电控制由合格电池/充电方案确认。**禁止将两块未经匹配/认证的锂电直接并联**，禁止只凭单颗充电 IC 的工作图推导双电池安全。
- 电量计需同时反映低电量负载压降；USB-C 按受约束充电设计，充电与佩戴同时使用是否允许以温升与标准评估决定。优先评估 buck-boost 而非把 R3 低压差 LDO 直接继承为量产方案。
- 未获得电芯真实可用 Wh 和各场景电池侧瓦数，不宣称续航。测试工况至少包含待机、交互显示、摄像/上传、双目高亮、通话、最坏并发、充电。

## 4. 初步重量分配预算（工程目标，不是样机实测）

| 模块 | 暂定质量上限 |
|---|---:|
| 金属镜框、双镜腿、铰链、鼻托 | 12 g |
| 双波导、双光机、显示相关结构 | 14 g |
| 主/副板、FPC、连接器、RF | 7 g |
| 两侧受保护电芯及电源辅件 | 9 g |
| 摄像头、音频、IMU、触控、USB-C | 6 g |
| 胶材、密封与装配余量 | 2 g |
| **合计工程目标** | **50 g** |

- **40 g** 是效果图的挑战性工业设计目标，不是目前已达到的指标；整机 R3 既有研发要求为裸镜 **≤50 g，55 g 警戒**。带处方镜片的配镜版本须另行称重。
- 上表是目标质量分摊，**光机/波导、两电池的实物规格未锁，质量上限可能需要调整**。任何一项超重，必须先优化体积、结构、集成度或光学方案，再申请外观目标变更。
- 外观轮廓优先锁定，但不要虚构具体镜腿宽厚；应由选定光机、电芯、FPC 弯折堆叠反推可行截面，再核对效果图比例。

## 5. 热、射频、结构与隐私不可妥协的门槛

- 靠近皮肤的热点：维持现有项目在指定 25°C 工况的接触温升目标 **≤41°C**，并审查不同环境/工作时长的适用安全标准；不得用平均功率替代最坏并发实测。
- 金属镜腿：射频天线不能简单放到连续金属腔体内，必须留射频窗口/天线净空；双目光机、FPC 和金属框还需要 EMI/EMC 验证。
- 结构：双眼光机、相机和镜腿铰链共享空间，先做真实零件 3D 堆叠/公差分析、镜架弯折疲劳与可维修设计。外观不可见的内侧局部加厚仅能在工业设计评审后进行。
- 隐私：中置摄像头的外向 LED 必须与采集能力形成故障安全的硬件联锁；实际镜头供电、时钟、指示灯同时观测。未经过真实 T11/T12 物理验证时 **`privacy_interlock_verified=false` 继续保留**。
- 声学：所谓「空间音频」需有声学与 DSP/传感器支持；开放式扬声器不能直接以独立音频 SoC 的 HFP 能力证明空间音频完成。

## 6. 并行研发计划与交付 Gate

| 路线 | 现在执行 | 阶段交付/不能越过的门槛 |
|---|---|---|
| A — EVT-0 R3→R4 | 保留既有 84 封装 PCB，解决 59 未连接、12 孔径错误、3 封装警告；ERC/DRC/电源/联锁持续推进 | 可复现 KiCad 工程、原生日志、真实封装与板厂制造约束；**不能因整机路线重置现有 R3** |
| B — EVT-1 ID 外观导向 | 先建立带尺寸标尺的正/侧/上 3D 包络、左/右镜腿纵向与截面堆叠，选左右光机+波导样件、电池包、主/副板外形；构建刚挠板接口 | 整机 STEP/3D、体积与重量表、双目光路/处方插片基准、FPC 动态弯折图、电源树、热/天线包络，均注明是否实物证实 |
| C — 可复用软件与协议 | Codex 维护 ESP-IDF、BLE/Wi-Fi、iPhone、HUD 等；定义由台架升级到双目显示的显示抽象层及硬件安全 Gate | 不删减 F01–F22、无授权不采集、未选光机不强行修改真实驱动；真实的手机/光学联调日志 |

**顺序**：① 冻结外观的**视觉特征**（非未测几何数值）→ ② 双目光机/波导/配镜联合选样和 3D 机械体积判定 → ③ 两镜腿板级架构与安全电源、音频、射频布局 → ④ 刚挠/FPC 原理图及 PCB → ⑤ 3D 打印空壳试戴与台架联调 → ⑥ EVT-1 真机样品、电/光/热/人体工学验证。
