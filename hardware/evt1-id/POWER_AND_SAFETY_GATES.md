# EVT-1 ID 电源架构与安全 Gate

版本：ID-HW-A01-PWR-01；日期：2026-11-12（Asia/Shanghai）。本文件是架构与测试输入，电池、充电管理、电源器件、阈值和电路均未选定；不构成可接线原理图、生产 BOM 或安全验证结论。

设计依据为用户附件《ZY AI/AR Glasses｜外观驱动硬件架构 V1.0》（ID-HW-A01），维持银色全框、中央相机、左右透明 AR 光路、纤细双镜腿、双侧电池、开放式音频、触控及右镜腿尾端 USB-C。F01–F22 的 16 P0、5 P1、1 预研保留。电池包真实尺寸及包络、光机、主控方案、音频平台与刚挠互连尚未冻结。

## 与 EVT-0 R3 的边界

EVT-1 双侧储能是新增整机架构任务。EVT-0 R3 的单电池 BQ24072、默认禁充、限流台架与摄像门禁保留在原工程；本文件不修改 R3 或固件，也不把其单电池电源路径复制为双电池方案。[TI BQ2407x 数据手册](https://www.ti.com/lit/ds/symlink/bq24072.pdf)定义的是单节充电管理，不能据此推导两个独立电池包的管理方式。

两块电池即便各有保护板，也不批准直接并联。左右两支路各自需要保护、NTC 温度采样、分路限流和隔离；保护状态、采样及故障切断不能只依赖 App 或主控任务调度。**统一充电管理、源选择、左右能量分配和隔离实现均为 TBD**。待电芯厂商与合格电池/电源设计人员共同评审后，才确定双独立充电通道或供应商明确支持的其他多电池管理方案。不得共用一个未经论证的温度读数来代表两侧电芯。

## 功能电源树

```text
  → 双电池充电与系统路径管理（拓扑、控制器、故障默认态 TBD）

       ├ 主控 / BLE / Wi-Fi 域（平台、电压、峰值、休眠电流 TBD）
       ├ 独立通话音频 / 麦克风 / 开放式扬声器域（平台与功率 TBD）
       ├ 左光机与显示驱动域（供应商轨、电平、时序、额定条件 TBD）
       ├ 右光机与显示驱动域（供应商轨、电平、时序、额定条件 TBD）
       ├ 中央相机域（LED 故障监测 + 采集硬件许可 + 受控供电；实现 TBD）
       └ 触控 / IMU / 状态 / 电量与双侧温度监控域（实现 TBD）
```

稳压架构需比较 buck-boost 等方案在已选电芯工作范围及脉冲负载下的效率、静态损耗、体积和热；目前不指定输出电压或器件。主控 A/B 平台应使用相同工况和测量边界比较，不能只比芯片数据手册的典型电流。左右光机各自登记电压、启动/关断顺序、突入电流、亮度条件和异常处理；公开裸微显示功率不得替代完整双目光机及驱动耗电。

跨前框和铰链的 FPC 需纳入支路压降、回流路径、故障隔离、信号断电反灌、弯折寿命和连接器温升评审。镜腿长度与截面、载流能力、弯折半径和温升边界全部待真实零件堆叠确认，不能从渲染图推导。

## 必需输入与功耗记录

`POWER_BUDGET.csv` 是缺项和待测工况表。数值 `TBD` 代表未知，不代表 0；`NA` 表示该行不适用。当前不存在已测 W、峰值 W、mAh、可用 Wh 或续航结果，不做数值合计或小时数宣传。

每侧必须取得：准确电芯/保护板版本和批次、化学体系、允许充放电电压/电流/温度、NTC 曲线与安装位置、保护动作及恢复条件、老化与膨胀边界、质量/尺寸公差、线束/端子极性、厂商验证材料。接触温度目标不能替代电芯温度许可；IC 热关断也不能替代电池包保护。TI 将过压、欠压、过流、短路等作为需检测的保护故障类别，本项目须逐项分配检测和切断职责，具体阈值继续 TBD。[TI 电池保护器官方总览](https://www.ti.com/product-category/battery-management-ics/battery-protectors/overview.html)

待测工况至少覆盖运输/关机、连接待机、双目交互 HUD、摄像与上传、双目高亮、HFP 通话、最坏允许并发、USB 充电、低电量及两侧状态不等、单支路失效、跨铰链压降和热稳态。当前只有默认拒绝门禁可用于台架；需要相机或光机的工况须在相应组件获准后执行，不以桩数据填入实测列。

每次记录测试样机和固件版本、左右包身份、两侧初始荷电状态与温度、环境温度、显示亮度/内容、音量、无线距离/重试、拍摄/上传频率、持续时间、仪器采样率/带宽/峰值统计窗口和校准信息。同步采集两侧电池端 V/I/NTC、USB 输入、关键稳压轨、复位与许可事件；原始数值波形与报告互相引用。平均功率和峰值必须说明窗口，不能用未标窗口的单次读数代替无线/显示瞬态。

只在拓扑已批准、放电试验有效且使用相同工况时，才能计算两支路实际向系统交付的能量：`E = ∫V(t)×I(t)dt`（换算为 Wh），并按真实截止/保护/切换条件确定可用能量。不得直接相加标称 mAh，或假定单边剩余能量总能被整机利用。若在电池端已计入转换损耗，续航估算不得再次乘同一效率。`t_est = E_usable / P_battery_avg` 只适用于已定义且复现的放电工作周期；实际续航仍需完整样机运行至规定截止条件。充电时的双向功率记录单列，不混入放电续航。

## 摄像硬件许可要求

中央外向 LED 的“小”是工业设计方向，可见性与故障安全须实测。采集许可必须与指示灯状态、相机轨和时钟建立硬件联锁。LED 开路、短路或监测链失效须撤销采集能力；具体检测覆盖与切断实现 TBD。仅将 LED 接在供电轨上不能证明灯故障时禁止采集。正常关闭、错误和撤销的流程应停采集与时钟、将 DVP/SCCB 等接口置安全高阻态、关闭相机供电，并测量余压和所有数据/控制线反灌；实际次序以最终模块和硬件切断评审为准。

在 T11/T12 真机证据审查通过前，保持 `privacy_interlock_verified=false`，不改变固件板级配置，不以强制跳线、软件提示、构建通过、模拟 JPEG 或元件数据手册替代安全验收。相机关闭的安全态必须覆盖开机、复位、欠压、看门狗和主控失联；恢复不得绕过重新授权及硬件许可。
