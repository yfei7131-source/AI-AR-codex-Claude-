### 3.1 P0｜PCB1 电气整改与真实布通明细
- **新增端到端真实布通（锁定规则，零悬空短桩，对应飞线均已消失）**：
  1. **`GND`（`U16:11 - U16:12`）**：顶层，线宽 `2 mil`，长度 `15.7 mil`，对象 ID `e951`。
  2. **`GND`（`U16:15 - U16:14`）**：顶层，线宽 `2 mil`，长度 `15.8 mil`，对象 ID `e952`。
  3. **`GND`（`U15:11 - U15:12`）**：顶层，线宽 `2 mil`，长度 `15.7 mil`，对象 ID `e953`。
- **失败尝试与即时回滚证据（零残留）**：
  - `ESP_VDD_SPI_3V3`（29 号焊盘 → `C14:1`）：`C14:1` 周边受相邻焊盘与板框阻挡，锁定规则下无法同层零违规直达，已撤销未连通线段并确认复测 `0 mil`。
  - `CAM_AVDD_2V8`（`C17:1` 顶层 ↔ `U6:1` 底层）：属跨层网络，尝试过程中产生的底层短桩 `e950`（`6.5 mil`）已删除并复测确认恢复 `0 mil`；相机 AVDD 关断、隐私联锁与电源隔离完全未受影响。
- **剩余 1 项 Netlist Error**：经网表对比确认 100% 仅源于 `J2 (J_CAM)`（广濑 [BM28B0.6-24DS/2-0.35V(53)](https://www.hirose.com/en/product/p/CL0673-5025-0-53)，26 脚，待相机模组 FPC 针位与官方 Land Pattern）及 `J3 (J_CHG)`（4 针磁吸接口 `MPN_TBD`），两者保持 `BLOCKED` 且 `转到PCB=是`，未虚构封装。

### 3.2 P1｜PCB2 去耦与布线核查
- 核实器件总数 **86**（C 33、D 1、J 3、MK 1、R 31、TP 1、U 15、Y 1），连接性错误 `237`，网表/间距/短路错误均为 `0`。
- 功能性 RC（`C2`、`C3`）与 AVDD 保护完整保留；在 `160 mil`（约 4 mm）窄板框与锁定 `0.152 mm`（6 mil）规则下，顶层被 QFN/0201 占满、底层被 AVDD 逻辑 IC 与 `FPGA_C...` 竖向走线束占满，8 颗去耦电容（`C5/C8/C9/C10/C11/C12/C31/C32`）须在后续将 `FPGA_C...` 线束整体迁入内层信号层时联合重构回流路径，本轮严守零新增间距错误原则未强行移位。

### 3.3 P2｜PCB3 U11 / 0.80 mm HDI 核查
- 核实器件总数 **53**（ANT 1、C 23、J 1、L 4、MK 1、Q 1、R 10、TP 6、U 4、Y 2），连接性错误 `134`，网表/间距/短路错误均为 `0`。
- 逐一评估外圈及非内圈未连通网络（`BLE_ANT_FEED` 跨整板长飞线、`BLE_RF_MID` 与 `LFXO_XL2` 顶/底跨层、`LFXO_XL1` 连至 U11 内圈过孔），在当前锁定规则下无同层无障碍短线可安全直连，未执行无效自动布线。
- 当前叠层仍为默认 6 层 `JLC06161H-3313`（1+4+1，总厚 `1.7873 mm`），仅定义 1 阶盲孔（`BV_L1_L2`/`BV_L5_L6`，孔径未绑定），[nRF5340-CMAA WLCSP95](https://www.yic-electronics.com/blog/QFN-vs-WLCSP-vs-BGA-Differences,PCB-Design,and-BLE-Applications.html)（`0.35 mm` 球距，需避光）在锁定 `0.152 mm` 规则下几何上无法完成内圈逃线；须先取得板厂针对 `0.80 mm` 2+N+2 顺序压合 HDI、[盘中孔 VIPPO](https://jlcpcb.com/blog/via-in-pad-pcb)（IPC-4761 Type VII）及 U11 局部细间距规则的书面 EQ 签核，未经板厂确认不宣称可制造。
