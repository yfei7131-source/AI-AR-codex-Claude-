# EVT-1 主机到 FPGA 的线协议

这份接口按 Rev D1.1 RTL 及本包原生仿真读取。ESP32-S3 先完成 iCE40 Target SPI 配置并遵守基线 ICD 的 49 个 SCK 要求，然后在 CS 高、SCK 低时切换 `QSPI_DIR1_EN` 到用户传输方向。主机、转换器和 FPGA 的板端引脚以有效网表为准。

用户传输时 CS 低有效。每个 SCK 上升沿读取 QIO[3:0]，每字节先高半字节。单次片选包含 1 字节命令、2 字节大端字地址、至少 1 个 16 位大端像素字；后续字地址自动增加。每眼合法范围为 0 至 19,199。A0/A1 写左/右立即缓冲，A2/A3 写左/右防撕裂缓冲。主机参考编码器在发送前拒绝越界和空写入。

A4 控制帧为 `A4 00 00 00 flags`。低三位依次是 SCAN_EN、OPT_PWR_REQ、RAW_ARM。OFF 时禁止扫描和 RAW；恢复后需要真实 VSYNC 脉冲才能解除门禁。启动和恢复时都要先确认 Rev D1.1 AVDD 监控链的状态，并遵守供应商确认的电源稳定时间。当前 JBD 实际稳定时间为 BLOCKED。

RAW_ARM 要求前一事务已关扫描且本次允许供电。下一 CS 周期原样镜像至双眼，结束后退出。RAW 体内部出现 A4 字节仍是透传数据。紧急硬复位和供电监控不依赖该命令。

`check_bridge.py` 用参考编码器生成真实线序，驱动原版 RTL 的 Icarus 仿真，核对连续地址、防撕裂标志、RAW 一次性镜像以及可解码的 OFF。ESP32 实板传输时序、JBD 初始化数据和供应商端 FPC 在台架证据可用前保留 BLOCKED。
