## 5. PCB3 U11（0.35 mm WLCSP）与 0.80 mm 2+N+2 HDI 可制造性收敛方案

### 5.1 现有默认叠层 vs 目标 HDI 叠层对比

| 关键工艺项 | 工程当前实测状态（不可直接投板） | 目标 0.80 mm 2+N+2 HDI 方案（需板厂书面 EQ） |
| :--- | :--- | :--- |
| **物理叠层与板厚** | 默认 6 层 `JLC06161H-3313`（1+4+1，总厚 **`1.7873 mm`**） | 目标 **`0.80 mm`（±0.1 mm）** 2+N+2 顺序压合 HDI（6 层或 8 层，需板厂给出精确介质厚度与 50 Ω/90 Ω 阻抗表） |
| **微盲孔与埋孔** | 仅定义 1 阶 `BV_L1_L2` / `BV_L5_L6` 且过孔尺寸绑定为空；无 2 阶盲孔 | 激光微盲孔 `L1–L2` + `L2–L3`（错位或叠孔，目标激光孔径 `0.075~0.10 mm`、焊盘 `0.18~0.20 mm`）+ 核心埋孔 |
| **盘中孔（VIPPO）** | 未配置 VIPPO 工艺规范 | 须采用 [盘中孔 VIPPO（IPC-4761 Type VII 树脂塞孔电镀填平）](https://jlcpcb.com/blog/via-in-pad-pcb) 防止回流焊锡芯吸 |
| **局部线宽/线距** | 全局锁定焊盘/过孔/导线间距 **`0.152 mm`（6 mil）**，无 BGA 区域规则 | 申请仅限 U11 区域内的局部 `3/3 mil`（`0.075/0.075 mm`）细间距 EQ；其余区域保持锁定规则 |
| **U11 物理约束与避光** | [nRF5340-CMAA WLCSP95](https://www.yic-electronics.com/blog/QFN-vs-WLCSP-vs-BGA-Differences,PCB-Design,and-BLE-Applications.html)（`4.390 × 3.994 mm`，`0.35 mm` 球距，标称高 `0.449 mm`，MSL 1） | 几何上在 6 mil 规则下 25/36 内圈球位不可逃线；且 WLCSP 侧面与锡球侧必须提供可见光/近红外避光防护（遮光胶或结构屏蔽）与 X-Ray 检验 |

### 5.2 若 0.80 mm 2+N+2 HDI EQ 未获批准的替代封装评估（不擅自重画整板）
- **替代封装候选**：Nordic [nRF5340-QKAA（aQFN94）](https://www.yic-electronics.com/blog/QFN-vs-WLCSP-vs-BGA-Differences,PCB-Design,and-BLE-Applications.html)（`7 × 7 mm`，`0.4 mm` 节距，最大高 `0.85 mm`，94 引脚，θJA `20.74 °C/W` 优于 WLCSP 的 `28.51 °C/W`，无需裸片避光）。
- **权衡约束**：`aQFN94` 内圈仍需 [1 阶激光微盲孔 / VIPPO（IPC-4761 Type VII）](https://devzone.nordicsemi.com/f/nordic-q-a/96530/nrf5340-aqfn94-pcb-trace-routing-for-inner-pads-via-in-pad)，可由 2+N+2 降为更易量产的 **1+N+1 HDI** 或嘉立创 6 层免费 VIPPO 工艺，但封装宽度 `7 mm` 超出当前 PCB3 约 `4 mm`（~140 mil）窄镜腿板宽，须与工业设计/结构（MECR-01）联合评估镜腿局部加宽与 40 g 重量预算后方可立项，本轮保持原 WLCSP 封装不动。

## 6. PCB2 8 颗去耦电容与 `FPGA_C...` 线束层间布线方案

- **保持现状**：保留功能性定时/滤波 RC（`C2`、`C3`）与 AVDD 硬件保护，维持 **0 间距错误、0 网表错误**。
- **层间协同方案**：
  1. **内层迁线**：将目前占用底层 `Y=460~850 mil` 空间的 `FPGA_C...` 竖向走线束整体迁入内层信号层（L3/L4），以 L2/L5 完整内电层作为紧耦合地参考平面。
  2. **底层就近回流**：在底层释放的通道内，将 `C5/C8/C9/C10/C11/C12/C31/C32` 贴近各自对应的底层 IC（`U5/U6/U10~U14`）电源脚摆放，单点短线入脚并紧邻打 `BV_L5_L6` 地孔回流至 L5 内电地层，全过程严守 `0.152 mm`（6 mil）锁定间距规则与 0 新增 DRC 错误门槛。
