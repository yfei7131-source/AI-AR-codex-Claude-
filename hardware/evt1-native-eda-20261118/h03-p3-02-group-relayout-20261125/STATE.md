## 三大模块成组重排与通道容量改善

1. **规则与约束差异修正（不重复 207 网分类）**：三板基础规则 `copperThickness1oz` 升级至 `min 3.0 / default 4.0 mil`、`Track↔Track 5.98 mil`；主干规则明确 `default 20.0 mil`（受控焊盘缩颈 `min 4.0 mil`）、支路规则明确 `default 10.0 mil`（`min 6.0 / 4.0 mil`），`pcb neckdown-plan` 待缩颈项 `0`，修复 `PCB1 R15.2` 走线穿焊盘。
2. **PCB1 电源阻容阵列成组重排**：成组重排 `11` 颗器件（`C31, R36, R29, R6, R27, C13, R13, R18, C34, R7, C30`），疏散 `y=1230..1340` 非电源砖墙（目标区器件 `8 -> 5`、`decap-too-far` `2 -> 1`）并聚类 `3V3_SYS` / `1V8_SYS` 阻容，拉近 `C31` 至 `U11.1`（`197.29 -> 159.46 mil`）；目标走廊最大连续无阻带宽 `8.0 -> 10.0 mil`；接入 `6` 颗 `4/10 mil` 盲孔与 `7` 条通道铜轨，`3V3_SYS` (`-1`) 与 `CAM_DOVDD_1V8` (`-1`) 净收敛，连接错误 `320 -> 318`。
3. **PCB2 VSYS 电容组成组重排**：成组重排 `3` 颗器件（`C1, C12, C9`），将插队的 `1V8_FPGA_IO C1` 移出 `VSYS` 电容列并把 `C9` 并入空位形成连续 4 颗 `C4-C9-C5-C10` `VSYS` 阵列（`C9 -> U11.5` 缩短 `160.68 -> 109.43 mil`、`C4-C9` 间距 `80.31 -> 21.60 mil`、`C5-C9` 间距 `52.00 -> 21.70 mil`），`C12` 上移释放西侧 `y=862..902` 通道（`C12 -> U11.5` 缩短 `199.66 -> 163.20 mil`，连续无阻带宽 `14.0 -> 42.0 mil`，可通行 4 mil / 6 mil 走线槽位 `0 -> 3`）；布通 `9` 条 `10 mil VSYS` / `6 mil GND` 通道铜轨，`VSYS` 开路 `25 -> 24`（`-1`），整板连接错误保持 `225` 且零间距违例。
4. **PCB3 U3 周边器件成组重排**：成组重排 `11` 颗器件（`TP4, TP5, R6, R10, R8, C12, C15, C17, C14, R5, R7`），外移 `TP4/TP5` 释放 `U3` 南侧逃线通道（`y=595..650` 连续无阻带宽 `0.0 -> 18.0 mil`，可通行 4 mil / 6 mil 槽位 `0 -> 1`），拉近 `R6` 距 `U3.2`（`128.24 -> 57.92 mil`）及 `R10` 距 `U3.7`（`142.11 -> 67.66 mil`），拉大 `1V8_SYS (C15/C17)` 与 `LFXO (C22/C23)` 隔离 `+100%`（`23.60 -> 47.33 mil`）；接入 `8` 颗 `4/10 mil` 盲孔与 `2` 条 `8 mil 1V8_SYS` 直连逃线，`1V8_SYS` (`-2`) 与 `GND` (`-2`) 净收敛，连接错误 `127 -> 123`。
5. **丝印保留与增量同步**：保留 P3-01 丝印清理成果（`0` 可见属性丝印、`257` 工程位号/BOM/CPL 完整、`54` 颗 `8 mil` SVG 方向圆点持久化保留），仅增量同步 `1` 处受 `C31` 移动影响的 `PCB1 U5` Pin 1 方向圆点（`(145.7, 1010.34) -> (73.7, 1052.4)`），未重做全板丝印。
