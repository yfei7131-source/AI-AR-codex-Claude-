## 隔离原生试验

- **K4 二阶 HDI**。在独立工作项目写入 7 个实际过孔记录与四层走线，包含 Ø100 µm 激光孔、L3–L4 机械埋孔、L2/L5 反焊盘。原生回读确认 K4 到 J1.P12 和 U10.C3 两条路径均导通。隔离项目 132 → 130 未连通，但有 4 个新增孔间距错误。三对同心叠孔的孔壁投影为 0 mil，另一对激光孔到埋孔为 5.3 mil，严格规则要求 11.8 mil。该试验保留物理层叠参数，采用逻辑层跨和现有原生规则验证，不代表制造商确认 0.80 mm。保留失败为证据，集成工程继续使用原有层跨和参考地。 [实测原生 DRC](verification/trials/hdi-k4-drc.json) · [路径与孔位结论](verification/trials/hdi-k4-native-outcome.json)
- **右板 C1–C8 的 1.8 V 支路**。隔离工程中添加实际 PTH、双面电源支线及功放控制绕行，原生证实供电和原有功放控制路径导通。严格 DRC 揭示 11.8 mil 板边及 10 mil 平面间距门槛，共 7 项新增违规。提高至实际门槛并保护 BLE 参考铜后，局部窗口没有同时可用的孔位置。集成工程保留 R5 电源和控制布线。 [拒收原始 DRC](verification/trials/PCB3-route-drc.json)
- **PCB1 J2**。实例化真实 C5577343 封装并重载，实读 28 个物理焊盘，4 个端部铜盘中 25/26 在同一端，27/28 在另一端。原厂定义两端电源触点，但实际端部电气连续性、防反及相机 FPC 针序仍须交叉验证。试件无分配网络，集成 PCB1 未放置 J2/J3。 [实物库几何回读](verification/trials/j2-footprint-geometry-witness.json) · [原厂图比较](pcb1/J2_HIROSE_AUDIT.md)
