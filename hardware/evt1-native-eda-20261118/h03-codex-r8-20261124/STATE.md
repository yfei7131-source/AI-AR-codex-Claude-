五条路径在原生铜箔回读里对照基线逐段复核，并在独立副本复现。PCB1 和 PCB3 有嘉立创原生 net-path 回执。PCB2 的 U4 使用 POLYGON 焊盘，使用原生回读的实际焊盘多边形及走线铜边计算正面积接触，并对照原生 DRC 消失的 U4.2、U4.1、C13.1 和接地过孔对象。PCB3 的 GND 原生 DRC 将一个遗留开路记录从 `b6246eedc0b362c3` 重新定位到其同铜岛的 `07cf1e6e5dfe3890`，两个既有图元的几何均已核对。

接入分支时，嘉立创自动拆分 PCB2 一条 3.5 mil 主干和 PCB3 两条既有 GND 线。PCB2 试写发生过重叠，经原生回读取消重叠并按原宽恢复主干右半段。最终逐条核对原主干的端点、铜宽和覆盖。三板设计记录的差异限于上述走线，另有编辑器生成的 LINE 占位记录。257 个器件、板框、叠层、过孔、平面、禁区和原生制造规则逐项一致。沿用既有 V4 盲孔几何子集，61／40／41 颗盲孔共 142 颗，匹配的项目规则子集检出 0 项违规。

## 研究接续与阻断

- **PCB1 J2/J3。** 沿用 #56/#57 的接口审查。J2 仍需实物 FPC 针序、极性和防反确认。J3 待配对件、额定电流与装配包络，PCB1 尾段实宽约 5.8 mm，候选件约 6.86 mm 的本体仍涉及结构修改。
- **PCB2 C11 与 FPGA。** #57 R8-C 的 C11 电源路径与 `d4ca5cb6211b4cf9` 既有 GND 铜相交，拟移动器件的包络有重叠。C11、八颗去耦电容、FPGA 线束与 MK2 声学约束的联合方案待调整。FPGA_CRESET_B、AVDD_QUAL_RC 等候选未找到满足现有走线约束的局部路径，信号在本轮无新增闭合。
- **PCB3 HDI。** 0.80 mm 二阶 HDI 仍待板厂确认，相关试验几何和 K5→L9 ECO 继续保留在专项分支。本轮使用现有叠层和现有过孔处理其他支路。
- **量产验收。** 剩余 701 处开路，仍需解决上述 ERC 与网表差异。整机重量、光学、声学、RF、阻抗、安全联锁实物测试及制造签核待验。工程维持 **NOT FOR FAB**。
