### 1.1 PR #44 激光盲孔不合规根因与全量整改（`154 → 0` 环宽不足盲孔）

- **PR #44 缺陷定位**：PR #44 中的全部 `154` 颗激光盲孔（`PCB1: 70`, `PCB2: 40`, `PCB3: 44`）采用 `4.0 / 8.0 mil`（`0.102 / 0.203 mm`），单边环宽仅 **`2.0 mil`（`0.051 mm`）**。核查 JLCPCB 与 PCBWay 官方 6 层 `1+4+1` HDI 工艺能力：

  - **PCBWay 6L HDI**：激光盲孔 `0.10 / 0.25 mm`（`4.0 / 10.0 mil`，`0.075 mm / 3.0 mil` 环宽）提供充足层间对准余量，降低顺次压合破环风险。
- **PR #45 整改落地（`independent_hdi_dfm_auditor_v2.py` 全量无截断验证）**：
  - **全部 `137` 颗狗骨激光盲孔（`BV_L1_L2 {1,15}` / `BV_L5_L6 {18,2}`）升级为 `4.0 / 10.0 mil`（`0.102 / 0.254 mm`，单边环宽 `3.0 mil = 0.0762 mm`）**，且保持距同层 SMD 焊盘铜皮 `≥ +1.25 mil`（零非 VIPPO 盘中孔）。
