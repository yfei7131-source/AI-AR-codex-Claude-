## 里程碑门槛
- Gate A：软件按键 / 摄像 / OCR+翻译 / HUD 合法授权闭环（可在模拟器）
- Gate B：AR 实机 HUD（非平面浏览器叠加）
- Gate C：自研 PCB 开发板样机与电池/音频/摄像通过电测
- Gate D：定制镜架集成与佩戴、温升、续航实测
- Gate E：全22功能按 P0/P1/R 做差异核验；首版至少16项 P0 可演示

## 仓库规范
每个任务需提交测试数据、日期、Git commit、限制与照片/日志。失败也需记录。未经结构验证不能宣称“可佩戴量产”；未经 ERC/DRC/电源审查不能生成“可下单PCB”。
