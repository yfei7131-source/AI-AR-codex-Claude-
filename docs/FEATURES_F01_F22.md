## 核心验收场景
- S1 即拍即问：物理按键触发、摄像授权、传图、AI 回答、HUD 显示。
- S2 AR 翻译：视野内文字成像、OCR、译文短句和 HUD 显示，不挡安全关键视野。
- S3 看见即行动：基于当前画面提取任务→显示任务卡→用户确认→执行白名单动作。

状态：本包仅部分验证软件流程，F01-F22 不是已完成功能清单。
